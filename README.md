# microscopy-3d-visualizer
A Python utility for loading, handling physical voxel spacing, and visualizing 3D confocal fluorescence microscopy cell datasets across orthogonal cross-sections and sequential volumetric z-stacks.


## Features

3D Volumetric Data Loading:** Loads and normalizes 3D fluorescence microscopy stacks (nuclei channel).
* **Voxel Calibration:** Computes anisotropic physical spacing ratios across Z, Y, and X axes.
Orthogonal Cross-Section Slicing:** Displays axial, coronal, and sagittal mid-planes.
Z-Stack Grid Display:** Visualizes stepped serial sections in a multi-panel subplot grid with uniform intensity scaling.
